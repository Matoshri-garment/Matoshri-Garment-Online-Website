1. Extract the ZIP file to a folder.
2. Keep index.html, style.css, script.js, and the images folder together.
3. Double-click index.html to open in Chrome or Edge.

COLOUR OPTIONS
Each product shows four colour options: Pink, Purple, Red and Blue. When a customer selects one, the product detail photo runs a local browser-based recolour preview that targets dark, nearly neutral pixels so a black garment can appear in the selected colour while retaining some shading and texture. This is NOT cloud AI or precise garment segmentation, so no guarantee of perfect garment-only recolouring is possible in this offline ZIP. Results depend on the photo: dark backgrounds, black hair/accessories, prints and embroidery may also be affected or may not recolour perfectly. For reliable AI garment-only recolouring, connect an image-editing AI service/API and configure its API key on a secure backend. Review every product photo before using this as a live shopping promise.

DRESS COLOR STUDIO
Open recolor.html or click “Dress Color Studio” in the store header. Upload a dress photo and select Pink/Purple/Red/Blue; the colour updates automatically, then use Download image. No brush is required and no AI account/API key is needed. The current automatic selector uses colour similarity, not a trained AI garment detector, so results vary by photo and perfect background preservation is not guaranteed. For best results, use a clear, centred dress photo with a contrasting background and check the preview before downloading.
